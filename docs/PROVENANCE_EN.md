# Provenance and project separation

FractalGo is the author's construct for topological diagnosis of trajectories and representations. This first distribution brings together the core executed in GRAVITAS, its bounded application and a dedicated interface. It does not validate every historical formulation of the construct.

Code and inputs originate from `general-relativity-and-inference`, commit `e8865c05cb30dc3179f16fb544483337ad6c2e10`. `provenance/IMPORTED_FILES.json` identifies each file by SHA-256. Older PDF transcriptions and the MadLab implementation are not represented as executed by this package. Private documents and article drafts are not published here.

Cassini inputs are inherited reconstructed matrices and an optical template. Their origin and conditions are documented in GRAVITAS; they are retained unchanged. The GP profile uses an estimate from an earlier benchmark, not recovered INPOP training costs. New records distinguish importing results from rerunning them.

Linux is checked for this delivery; Windows/macOS launchers are prepared but native execution on those systems is not claimed. Public availability grants no additional licence: see LICENSES.md.
